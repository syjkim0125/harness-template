# Step 4: E2E 테스트

## 작업 내용
- 핵심 사용자 여정(end-to-end) 테스트 작성
- 인증 플로우 (로그인 → 권한 확인 → 로그아웃)
- 주요 CRUD 플로우 (생성 → 조회 → 수정 → 삭제)
- 에러 시나리오 (네트워크 실패, 인증 만료, 권한 부족)
- CI 파이프라인에 E2E 테스트 통합

## AC (Acceptance Criteria)
- [ ] 핵심 사용자 여정 E2E 테스트 1-2개 동작
- [ ] 인증 플로우 E2E 테스트 통과
- [ ] CI에서 E2E 테스트 자동 실행
- [ ] flaky 테스트 0건
- [ ] E2E 테스트 실행 시간 < 5분
