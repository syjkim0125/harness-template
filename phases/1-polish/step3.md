# Step 3: 문서 정비

## 작업 내용
- `docs/PRD.md` — 실제 프로젝트 정보로 전체 채움
- `docs/ARCHITECTURE.md` — 선택한 아키텍처 구체화 + 다이어그램
- `docs/ADR.md` — 지금까지의 기술 결정을 ADR로 기록
- `docs/UI_GUIDE.md` — 실제 색상, 컴포넌트, 타이포그래피 정의
- `README.md` — 프로젝트별 실행 명령, 기여 가이드
- `CLAUDE.md` — `{기술 스택}`, `{개발 명령어}` placeholder 실제 값으로
- `.env.example` — 프로젝트 필수 환경변수 전체 나열

## AC (Acceptance Criteria)
- [ ] 모든 문서에 `{...}` placeholder가 실제 값으로 치환됨
- [ ] README에 빠른 시작(git clone → 실행) 절차 명확
- [ ] ARCHITECTURE.md에 실제 데이터베이스, 외부 서비스, 환경변수 기술
- [ ] ADR에 핵심 결정(프레임워크, DB, 인증 방식 등) 기록
