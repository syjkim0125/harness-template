# Step 0: 프로젝트 초기 설정

## 작업 내용
- 프로젝트 구조 스캐폴딩
- 패키지 매니저 초기화 및 의존성 설치
- 환경변수 설정 (`.env.example` → `.env`)
- 린트/포맷터/테스트 프레임워크 설정
- Git 저장소 초기화 및 `.gitignore` 적용

## AC (Acceptance Criteria)
- [ ] `npm install` (또는 해당 패키지 매니저) 성공
- [ ] `npm run dev` 실행 시 서버 시작
- [ ] `npm run lint` 에러 없이 통과
- [ ] `.env` 파일에서 기본 설정 읽음
- [ ] 빈 테스트 스위트 실행 성공
