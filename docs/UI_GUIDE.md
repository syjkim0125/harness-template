# UI 디자인 가이드

## 디자인 원칙
1. **기능 우선** — 매일 쓰는 도구처럼 보여야 한다. 마케팅 페이지가 아니다.
2. **정보 밀도 높게** — 데이터 대시보드는 한 화면에 많은 정보를 보여줘야 한다.
3. **일관된 패턴** — 같은 작업은 항상 같은 방식으로 동작해야 한다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text (배경 그라데이션 텍스트) | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 기능이 아니라 장식. 사용자에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 동일한 과도한 border-radius | 균일한 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb (blur-3xl 원형) | 모든 AI 랜딩 페이지에 있는 장식 |

## 색상
프로젝트별 색상은 `docs/PRD.md` 또는 브랜드 가이드를 참조한다.

### 일반적 권장 사항
| 용도 | 권장 |
|------|------|
| 페이지 배경 | 어두운 톤 (#0a0a0a 범위) 또는 순백 (#ffffff) |
| 카드 배경 | 페이지 배경보다 한 단계 밝게/어둡게 |
| 주 텍스트 | 배경과 대비가 충분한 색상 (WCAG AA 4.5:1) |
| 보조 텍스트 | 주 텍스트보다 2-3단계 어두운/밝은 톤 |

### 데이터/시맨틱 색상
| 용도 | 권장 |
|------|------|
| 성공 | 녹색 계열 (#22c55e 범위) |
| 에러 | 적색 계열 (#ef4444 범위) |
| 경고 | 황색/주황 계열 (#f59e0b 범위) |
| 정보 | 청색 계열 (#3b82f6 범위) |

## 컴포넌트
### 카드
- border-radius: 6-8px (과도하게 둥글지 않게)
- border: 1px 미세한 구분선
- padding: 16-24px
- hover 시 미세한 elevation 변화 (선택)

### 버튼
- Primary: 배경색 + 명도 대비 텍스트, hover 시 10% 어둡게
- Secondary: 테두리 + 투명 배경
- Text: 텍스트만, hover 시 밑줄 또는 색상 변화
- 높이: 36-40px, padding: 8px 16px

### 입력 필드
- border: 1px 구분선, focus 시 색상 변화
- padding: 8px 12px
- 높이: 버튼과 통일 (36-40px)
- 에러 시 border 색상 변경 + 에러 메시지 표시

## 레이아웃
- 최대 너비: 1200px (대시보드), 720px (폼/설정)
- 사이드바 + 메인 구조 권장
- 컴포넌트 간 간격: 12-16px, 섹션 간: 24-32px

## 타이포그래피
- 페이지 제목: 24-28px, semi-bold
- 섹션 제목: 18-20px, medium
- 본문: 14px, regular, line-height 1.5-1.6
- 보조: 12-13px, muted color

## 애니메이션
- 허용: fade-in (0.2-0.3s), slide-up (0.3s), loading spinner
- 금지: bounce, scale bounce, elastic, parallax

## 반응형
| Breakpoint | 너비 | 용도 |
|------------|------|------|
| Mobile | < 640px | 세로 스택, 사이드바 hidden |
| Tablet | 640px ~ 1024px | 2단 그리드 |
| Desktop | > 1024px | 사이드바 + 메인 |

## 접근성
- [ ] 모든 이미지에 alt 텍스트
- [ ] 키보드 네비게이션 가능
- [ ] 색상 대비 WCAG AA 기준 충족 (4.5:1)
- [ ] 포커스 상태 명시적 표시
- [ ] ARIA label 필수 요소에 적용
- [ ] reduced-motion 선호 시 애니메이션 제거

## 아이콘
- SVG 인라인 사용
- 크기: 16-20px (텍스트와 동일한 라인 높이)
- 아이콘 컨테이너(둥근 배경 박스)로 감싸지 않는다

## 모션 프리퍼런스
- `prefers-reduced-motion: reduce`일 때 모든 애니메이션 제거
- 트랜지션: 200ms ease-in-out
