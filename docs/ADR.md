## ADR 프로세스
1. 결정이 필요한 이슈를 식별
2. 대안 목록과 각각의 장/단점 정리
3. 선택한 안과 이유 기록
4. 팀 리뷰 후 확정
5. 구현 후 ADR에 결과 반영
